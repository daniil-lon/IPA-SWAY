## Создание карточки

- Тип: «Универсальное» (мобильное приложение, отдельная ТВ-версия не подготовлена).
- Распространение: «Бесплатное», если установка должна быть бесплатной.
- Название в консоли: `Sway`. По форме консоли это внутреннее неизменяемое имя.
- Публичное название: `Sway` — проверить уникальность в консоли.
- Категория: выбрать подходящий музыкальный раздел из текущего списка консоли.
- Сайт: https://music.academmix.ru
- Контакт поддержки: требуется указать реальный действующий контакт владельца.
- Возрастная маркировка: определить после проверки итогового каталога и текстов.

## Текст карточки — черновик

Краткое описание:

Музыка, персональная волна, плейлисты и любимые треки в одном приложении.

Полное описание (сверить возможности с окончательной сборкой):

Sway — музыкальное приложение для повседневного прослушивания.
Находите музыку, сохраняйте любимые треки и собирайте свои плейлисты.

Персональная волна помогает выбирать музыку с учётом ваших предпочтений.
Настраивайте звучание с помощью эквалайзера и управляйте воспроизведением
через системный плеер Android.

Для поиска и прослушивания музыки требуется подключение к интернету.
Доступность отдельных записей зависит от источника.

Метаданные получены через `aapt dump badging` непосредственно из APK.
Проверка подписи и метаданных не подтверждает готовность приложения к выпуску.

Существующий ключ находится в `.private/android/sway-release.jks`, настройки —
в `.private/android/signing.properties`. Сохранить резервную копию обоих файлов

Обновления APK должны сохранять идентификатор пакета и подпись; versionCode
должен расти. Новый ключ для этого приложения не генерировать.

## Перед загрузкой финальной версии

- Проверить на Android вход/выход, поиск, воспроизведение, переход между треками,
  фоновую работу при блокировке экрана, уведомление и системные кнопки плеера,
  работу после отказа в уведомлениях и восстановление после потери сети.
- Приложение загружает https://music.academmix.ru в WebView и использует
  нативный сервис воспроизведения. Проверять нужно также актуальную серверную
  версию: изменение сайта меняет поведение установленного приложения.
- Подготовить иконку 512×512 PNG/JPG до 3 МБ с заполненным фоном без прозрачного
  контура. Текущий launcher icon не считать автоматически готовой иконкой магазина.
- Подготовить минимум три реальных скриншота окончательного мобильного интерфейса.
  PNG/JPG, до 3 МБ каждый, максимум 2160×3840; в форме выбрать вертикальную
  ориентацию для портретных снимков.
- Подготовить опубликованную политику конфиденциальности с фактическими данными
  владельца, обработкой данных, контактами и порядком удаления аккаунта/данных.
  При выборочном поиске готовая страница политики в проекте не найдена.
- Заполнить декларацию данных по фактической обработке: Яндекс ID, профиль,
  загруженные изображения, коллекция и сигналы прослушивания требуют проверки.
  Не отмечать «данные не собираются» без аудита.
- Сверить разрешения APK: INTERNET, ACCESS_NETWORK_STATE, FOREGROUND_SERVICE,
  FOREGROUND_SERVICE_MEDIA_PLAYBACK, POST_NOTIFICATIONS, WAKE_LOCK, VIBRATE;
  также присутствует собственное DYNAMIC_RECEIVER_NOT_EXPORTED_PERMISSION.
- Закрыть отмеченные в `LEGAL.md` вопросы подтверждения прав на аудио, тексты
  и изображения. Этот документ не подтверждает наличие лицензий.

Пока приложение разрабатывается, карточку можно готовить как черновик.
По документации RuStore обработанные установочные файлы хранятся 14 дней,
если не отправить версию на модерацию; загружать окончательный APK лучше ближе
к готовности. Для первого выпуска допустим подписанный APK, AAB не обязателен.
