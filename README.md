# Sway

Сейчас разрабатывается и публикуется **только версия для iPhone**.

| Папка | Содержимое | Публикация |
| --- | --- | --- |
| `iphone/` | Safari / приложение с главного экрана, плеер, каталог, Cloudflare Worker и серверные модули | `music.academmix.ru` |
| `android/` | Проект Android и готовые APK в `releases/` | Отдельная сборка; в iPhone-релиз не входит |
| `desktop/` | Приложение для ПК со своим интерфейсом и сборкой | Отдельная сборка; в iPhone-релиз не входит |
| `artifacts/` | Отчёты проверок и зафиксированные снимки релизов | Сами по себе не публикуются |

Из корня: `npm run dev`, `npm run predeploy`, `npm run test` запускают iPhone-проект. `npm run deploy` проверяет платформу и публикует только `iphone/public` и iPhone Worker. Разработка Android и ПК сейчас приостановлена.

В `iphone/` находятся ссылки на общие служебные папки (`artifacts`, `.private`, `.tools`, `.wrangler`); это не копии клиентских приложений. Музыкальная библиотека сохранена без повторного копирования аудио. Старые зафиксированные релизы в `artifacts/` остаются для восстановления.

Подробнее о текущем веб-приложении: [iphone/README.md](iphone/README.md).

Общая проверка проекта из корня: `node scripts/check-project.mjs` (сервер, хранилище, безопасность, десктоп и синтаксис), затем `node scripts/check-project.mjs --ui` (дополнительные браузерные сценарии). Основной iPhone-прогон: `npm test`. Журналы и сводки сохраняются в `artifacts/project-audit/`; результаты отдельного iPhone-прогона зависят от выбранного перенаправления вывода.

Проверка Android из `android`: `gradle --no-daemon :app:compileDebugJavaWithJavac :app:lintDebug`. Используется установленный Gradle 8.10.2 и Java 17. Первый lint требует загрузки AndroidX-зависимостей; после загрузки работает `--offline`. Это проверка исходников, а не проверка APK на устройстве.

`npm test` выполняет актуальные автономные проверки iPhone: запуск, обновление, передачу аудио, офлайн и интерфейс. Старый `iphone/scripts/check.mjs` проверяет прежний ПК-плеер и старые координаты; он сохранён как историческая проверка. Для сетевых замеров: из `iphone` запустить `node scripts/diagnose-network-path.mjs` и `node scripts/check-iphone-audio-delivery.mjs`; результаты сохраняются в `artifacts/network-performance`. Синтетический MP3-тест использует уже установленный ffmpeg, при другом расположении путь передаётся в `SWAY_FFMPEG`.
