# Интерфейс Sway

| Возможность | Где реализована | Поведение |
| --- | --- | --- |
| Навигация | Маршруты по хэшу и нижняя панель в `public/app.js` | Свайп переключает верхние вкладки на телефоне. Строки поиска, горизонтальные ленты, диалоги и органы плеера обрабатывают свои жесты. |
| Подборки | `public/wave-deck.js` | Свободная прокрутка с привязкой к центру. Кнопки и стрелки на клавиатуре дают альтернативу жесту; проигрывание запускается выбором карточки. |
| Профиль | `public/profile-ui.js`, `profile-store.mjs` | Изменения сохраняются через форму. Фото из Яндекс ID остаётся в личном профиле; по ссылке видны только данные, открытые владельцем. |
| Перемотка и EQ | Нативные диапазоны в `public/app.js`, общие аудиомодули | Касание или клавиатура остаются доступны. Во время перетаскивания отображается будущая позиция; проигрыватель переходит туда после отпускания. |
| Подтверждения и ошибки | `notice()` и локальные статусы форм | Текст на русском; важная ошибка остаётся в соответствующем экране. Поддерживаемые телефоны могут дать короткий тактильный отклик только на жест пользователя. |
