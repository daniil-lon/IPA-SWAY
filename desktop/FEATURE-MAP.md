# Состояние настольной версии 1.2

Sway использует местную библиотеку проекта: 7000 композиций, 2770 альбомов и 882 исполнителя. Это отдельное приложение для Windows. Его коллекция и рекомендации пока не связаны с аккаунтом Яндекса.

## Что добавлено

| Возможность | Состояние в Sway |
| --- | --- |
| Очередь | «Играть следующим», добавление в конец, удаление отдельных вхождений, перемещение кнопками и перетаскиванием, очистка следующих треков |
| Повтор и перемешивание | Вся очередь / один трек; перемешивание без повторения одного вхождения до конца прохода; переход назад по истории перемешивания |
| Восстановление плеера | Очередь и позиция сохраняются; после запуска музыка ждёт нажатия воспроизведения |
| Альбомы и исполнители | Независимое добавление в коллекцию; сохранение альбома не ставит лайки всем его трекам |
| Закрепление | Плейлисты, альбомы и исполнители в боковом меню; изменение порядка перетаскиванием |
| Плейлисты | Создание, название, описание, обложка через системный выбор изображения, добавление и удаление треков, порядок треков, удаление с подтверждением |
| Поиск внутри списков | Название, исполнитель, альбом; сортировка и фильтр жанра; выбор нескольких треков для воспроизведения, очереди и избранного |
| Перенос плейлиста | Экспорт и импорт файла `.sway-playlist.json`; переносится список известных приложению треков, сами аудиофайлы в него не входят |
| Глобальный поиск | Треки, альбомы, исполнители и собственные плейлисты; отдельная сохраняемая история запросов |
| Тексты | Архив содержит 4054 текста, из них 2754 с временными отметками; подсветка строки, прокрутка за музыкой, перемотка нажатием, режим полного текста |
| Эквалайзер | Настоящая обработка аудио: 10 полос, 6 пресетов, собственная кривая, усиление и ограничитель пиков; настройка сохраняется |
| Таймер сна | 5–90 минут либо до конца текущего трека |
| Импорт музыки | Реестр выбранных аудиофайлов сохраняется после закрытия; MP3, M4A, FLAC, WAV, OGG, Opus, AAC; удаление записи не удаляет исходный файл |
| Книги и подкасты | Добавление своих файлов; отдельный раздел и сохранение места прослушивания |
| Скорость | 0,5–2× в раскрытом плеере |
| Управление Windows | Кнопки окна, системные медиакнопки через Media Session, меню в трее, настройка закрытия в трей |
| Горячие клавиши | Пробел, Ctrl+стрелки, Ctrl+F, Alt+стрелки, Escape; перемещение по всплывающим меню клавишами |
| Моя волна | Местный подбор учитывает любимые треки, исполнителей, жанры, прослушивания, быстрые пропуски и исключения; волна по треку / альбому / исполнителю / плейлисту |
| Настройки волны | Разная / любимая / незнакомая музыка, настроение, алфавит имеющегося текста: кириллица / латиница / смешанный |

## Что ещё требуется для всех возможностей Яндекс Музыки

| Возможность оригинала | Что отсутствует |
| --- | --- |
| Аккаунт, Яндекс Плюс и синхронизация | Авторизованное подключение к музыкальному сервису; местный профиль Sway не является аккаунтом Яндекса |
| Весь актуальный каталог и поиск сервиса | Сейчас используется каталог проекта; новые релизы автоматически с Яндекса не поступают |
| Оригинальная персонализация | Местная волна не воспроизводит закрытые алгоритмы Яндекса |
| Lossless и выбор качества потока | Нужны соответствующие источники аудио; интерфейс показывает фактический формат файла, без фиктивного переключателя качества |
| Онлайн-каталог подкастов и книг, подписки и новые выпуски | Сейчас доступны только добавленные пользователем файлы |
| Концерты и билеты | Афиша и покупка билетов не подключены |
| Совместные и публичные плейлисты, ссылки на коллекции, друзья | Нужны сервер, права доступа и синхронизация между пользователями |
| Устройства и управление воспроизведением между ними | Работает только этот компьютер |
| Загрузки из облачного каталога | Местная библиотека уже доступна без сети; загрузчик защищённых потоков сервиса не реализован |
| Трейлеры, клипы, видеоверсии, DJ и специальные подборки сервиса | Нет соответствующих источников и сервисной интеграции |
| Кроссфейд, выравнивание громкости всего каталога, бесшовные переходы | Не реализованы; обычная смена треков использует один аудиоэлемент |

## Визуальное совпадение

Главная, начальный поиск и коллекция сверялись со снимками установленной Яндекс Музыки 5.86.0 при 1280×800. Взяты локальные шрифты, статические векторные иконки, изображение сердечка и штатная видеопетля волны. Каркас окна, ширина бокового меню, нижний плеер и геометрия поиска уточнялись по координатам. Пять обложек разделов поиска — снимки эталонного экрана.

Новые меню, очередь, тексты и настройки оформлены в той же палитре и типографике. Их полное совпадение с оригиналом по пикселям пока не доказано: доступны не все эталонные состояния. Sway сохраняет своё название и каталог. Видеопетля волны не воспроизводит всю интерактивную анимацию оригинала. Единого подтверждённого процента сходства нет.
