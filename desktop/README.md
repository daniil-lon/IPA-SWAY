# Sway для Windows

Отдельное настольное приложение. Исходники мобильного сайта и его сервер не меняются.

Главная, коллекция и поиск построены по снимкам установленной Яндекс Музыки 5.86.0 при размере окна 1280×800: панель 224 px, содержимое с отступом 32 px сверху, плеер 80 px. Подключены локальные шрифты, статические иконки, штатная видеопетля «Моей волны» и изображение сердечка образца. Пять обложек разделов поиска взяты с его экрана. В версии 1.1 дополнительно уточнены размеры и начертания текста, цвета, поле поиска, отступы и наведение на обложки. Название Sway, музыкальный каталог и пользовательские данные относятся к текущему проекту; визуальная идентичность всех экранов не подтверждена.

Версия 1.2 добавляет редактирование и сохранение очереди, отдельные любимые альбомы и исполнителей, закрепление в меню, поиск и сортировку внутри списков, выделение треков, редактирование и перенос собственных плейлистов. Тексты с временными отметками следуют за музыкой и перематывают её по нажатию строки. Эквалайзер обрабатывает звук, таймер сна останавливает воспроизведение. Импортированные аудиофайлы сохраняются после закрытия; книги и подкасты из файлов помнят позицию. Полный список реализованного и оставшихся сервисных функций: [FEATURE-MAP.md](FEATURE-MAP.md).

Проверки и ограничения: [QA.md](QA.md). Источники локальных визуальных ресурсов: [REFERENCE-ASSETS.md](REFERENCE-ASSETS.md).

## Запуск

Откройте `Start Sway.cmd`. При первом запуске распаковывается уже имеющийся в локальном кэше Electron 45.3.2. Установка программ и загрузка пакетов не требуются. Приложение использует существующую папку `../public` с каталогом, обложками и 7000 аудиофайлов. Профиль, избранное и настройки настольной версии отделены от сайта и сохраняются в `desktop/.data`.

## Сборка

Запустите `powershell.exe -NoProfile -ExecutionPolicy Bypass -File desktop/scripts/build.ps1` из корня проекта. В `desktop/release/Sway-ДАТА-ВРЕМЯ/` появится `Sway.exe`. По умолчанию сборка обращается к существующей музыкальной библиотеке этого компьютера и требует сохранения папки проекта на прежнем месте. Это позволяет не создавать вторую копию 30 ГБ музыки.

Для полностью автономной переносимой папки используйте `desktop/scripts/build.ps1 -FullMedia`. Этот вариант копирует весь каталог и требует более 30 ГБ свободного места. Отдельный установщик не создаётся.

## Проверка

- `node desktop/scripts/check-runtime.cjs` — доступ к каталогу, частичное чтение и перемотка аудио, границы доступных папок.
- `node --test desktop/scripts/features-model.test.cjs` — очередь, перемешивание, разбор текстов, рекомендации и постоянный реестр файлов.
- `node desktop/scripts/features-qa.cjs` — сценарии в настоящем открытом приложении с восстановлением коллекции после проверки.
- `node desktop/scripts/native-import-qa.cjs` — два перезапуска с отдельным профилем, декодирование импортированного MP3 и частичное чтение.
- `node desktop/server.cjs` — просмотр интерфейса в браузере по `http://127.0.0.1:8798`.
- `desktop/Start Sway.cmd --smoke` — запуск Electron без показа окна, проверка каталога и снимок в `desktop/artifacts`.
- `desktop/Start Sway.cmd --inspect-ui` — отладочный интерфейс на `127.0.0.1:9238`, доступный только при явном запуске с этим флагом.
- `desktop/Start Sway.cmd --reference-size` — окно 1280×800 для сопоставления с оригиналом. Можно указать другой размер как `--reference-size=1440x900`.

## Интерфейс окна

В интерфейсе доступен `window.desktop`: `minimize()`, `maximize()`, `close()`, `windowState()`, `onWindowState(callback)`, `pickAudio(kind)`, `localLibrary()`, `removeLocal(id)`, `localDuration(id, seconds)`, `pickCover()`, `exportPlaylist(playlist)`, `preferences(update)`, `onMediaAction(callback)`. Метод `maximize()` переключает развёрнутое состояние. Область перетаскивания задаётся CSS-свойством `-webkit-app-region: drag`, кнопки внутри неё — `no-drag`.

`pickAudio()` открывает системный выбор MP3, M4A, FLAC, WAV, OGG, Opus и AAC. Только явно выбранные файлы добавляются в реестр `.data/imported-library.json` и доступны проигрывателю по адресам с идентификаторами, без передачи интерфейсу путей на диске. Реестр сохраняется между запусками. Удаление записи из библиотеки не удаляет исходный аудиофайл. Если файл перемещён или удалён вне Sway, прежняя запись не сможет его открыть. При проверке `--smoke` используется отдельный профиль `.data-smoke`.

Локальные ресурсы доступны относительно `sway://app/`: сначала файлы `desktop/ui`, затем файлы библиотеки `public`. Аудио передаётся потоком с поддержкой HTTP Range; весь файл в память не загружается. В интерфейс не передаются Node.js, прямой доступ к файлам или произвольные IPC-каналы. Новые окна и переходы за пределы приложения запрещены.

Тексты доступны как `/lyrics/{id}.json` из существующей папки `lyrics_archive`. Формат: `trackName`, `artistName`, `plain`, `synced` (строка LRC), `lines` (массив `{at, text}`, время в секундах).
