# Sway для iPhone

Приложение открывает music.academmix.ru на весь экран (WKWebView) и добавляет то, чего нет у сайта в Safari:

- музыка играет в фоне и при заблокированном экране;
- системный виброотклик Taptic Engine: щелчки при прокрутке ленты станций и фильтров, мягкий толчок при перелистывании трека, твёрдый при «Играть», двойной при «Мне нравится», сильный при «Встряхнуть»;
- service worker работает и в приложении (WKAppBoundDomains), поэтому скачанные треки и загрузка кусками на режущей сети тоже работают.

## Как получить .ipa

Собрать .ipa можно только на macOS с Xcode, на Windows нельзя. Сборку делает GitHub Actions на бесплатном macOS-сервере:

1. Загрузить проект в репозиторий на GitHub.
2. Открыть вкладку **Actions**, выбрать **iOS IPA** и нажать **Run workflow**. Сборка также запускается сама после изменений в `ios/`.
3. Через 5–10 минут скачать артефакт **Sway-ipa** (zip с `Sway.ipa` внутри).

На Mac можно собрать и вручную: `brew install xcodegen`, затем в папке `ios/` выполнить `xcodegen generate` и открыть `Sway.xcodeproj`.

## Как установить на iPhone

`Sway.ipa` не подписан. Подпишите его своим Apple ID при установке:

- **Sideloadly** (Windows): подключить iPhone кабелем, перетащить `Sway.ipa`, ввести Apple ID и нажать Start. С бесплатным Apple ID подпись действует 7 дней, потом установку нужно повторить (данные приложения сохраняются).
- **AltStore**: то же самое, и он сам продлевает подпись по Wi-Fi.

На iPhone потом включить: Настройки → Конфиденциальность и безопасность → Режим разработчика (iOS 16+). Затем Настройки → Основные → VPN и управление устройством → доверять своему Apple ID.
